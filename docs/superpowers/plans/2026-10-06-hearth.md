# Hearth v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Ship a macOS app that installs and runs a private Apache, MariaDB, and PHP stack. Programs live in `/opt/hearth`. The database, config, and logs live in `~/Library/Application Support/Hearth`.

**Architecture:** Pure planners and config renderers decide ports, resume steps, launchd state, and file contents. An actor, `StackController`, performs process, Keychain, and file work behind protocols. SwiftUI reads a `@MainActor` model.

**Tech Stack:** Swift 6, SwiftUI, Swift Testing, Xcode 27, macOS 15 deployment target, CryptoKit, Security.framework, launchctl.

**Spec:** `docs/superpowers/specs/2026-10-06-hearth-design.md`

## Global Constraints

- Bundle identifier `com.jerodprice.hearth`. App Sandbox off. Hardened Runtime off. `SWIFT_STRICT_CONCURRENCY` complete. Do not hand-edit `project.pbxproj` after Xcode creates it; build settings go through Xcode.
- Private prefix only. Never invoke `/opt/homebrew/bin/brew`.
- Bind `127.0.0.1` only. Preferred ports HTTP 8888, MariaDB 8889, PHP-FPM 9000.
- Adminer 6.1.1 MySQL English build. SHA-256 `cd5d65d3e85c9e1233126625232150e2de405f3d56c76fdc171f4133a401e8d2`.
- Root password is 24 characters from `A-Za-z0-9`, stored in Keychain service `com.jerodprice.hearth` account `mariadb-root`, accessible when unlocked.
- Launch agent labels: `com.jerodprice.hearth.httpd`, `com.jerodprice.hearth.php-fpm`, `com.jerodprice.hearth.mariadb`.
- Start order MariaDB, PHP-FPM, Apache. Stop order Apache, PHP-FPM, MariaDB.
- Blocked copy: `Database files exist and Hearth has no saved root password.`
- Newer-data copy: `This Hearth data was written by a newer version`
- No free port copy: `Hearth could not find a free port`
- Busy saved port copy: `127.0.0.1:N is in use`
- Unit tests do not run brew, download Adminer, or touch the real Keychain.
- No product names from outside this stack appear in the app or the docs this plan adds.

## Review Focus

- A saved port held by Hearth's own running agent must not abort Continue setup. A busy port whose agent is not loaded must.
- Quitting during setup must signal the installer process group, not only the app.
- `Apply password` connects without a password first and falls back to the Keychain password without printing the SQL into the log.
- `stack.json` version other than 1 shows the newer-version message and does not start services.
- Document-root changes rewrite Apache only, and restart Apache only when that agent is loaded.
